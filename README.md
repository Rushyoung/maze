# amaze

Amaze is a maze game written in Python.  
It is a simple game just for exercise.  

## Requirements
```bash
pip install -r requirements.txt
```

## Start the game
```bash
python -u main.py
```

## Developing
To run the game in development mode, you can use the following command:
```bash
cd Amaze
python -m venv .
Scripts/activate
# or source bin/activate on Unix-like systems
pip install -r requirements.txt
python -u main.py
```
